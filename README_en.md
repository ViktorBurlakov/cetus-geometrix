# 📚 Архітектура та Ключові Принципи Geometrix

## 1. Конструктивна Твердотільна Геометрія (CSG)

Бібліотека Geometrix використовує підхід **Constructive Solid Geometry (CSG)** для моделювання складних 2D перерізів:

* **CSG-дерево:** Геометрія представлена як бінарне дерево:
    * **Листя (Primitives):** Базові геометричні фігури (`Rectangle`, `Polygon`).
    * **Вузли (Compounds):** Складені об'єкти, що представляють результати булевих операцій (`Union`, `Difference`, `Intersection`).
* **Незмінність (Immutability):** Усі геометричні об'єкти є незмінними. Будь-яка операція повертає **новий** об'єкт, забезпечуючи цілісність структури даних.

## 2. Гібридний Підхід до Обчислень

Використовуються як точні, так і гнучкі методи розрахунку інерційних властивостей:

1.  **Аналітичні Обчислення (Точність):** Для простих примітивів (`Rectangle`) використовуються точні математичні формули.
2.  **Чисельні Обчислення (Гнучкість):** Для довільних полігонів (`Polygon`) та результатів складних CSG-операцій використовується **формула Гаусса-Гріна (Gauss-Green formula)** для інтегрування по контуру.

## 3. Принцип Делегування

* **Compound (Вузол):** Зберігає посилання на операнди (`left`, `right`) та об'єкт операції (`CSGOperation`).
* **CSGOperation (Логіка):** Бере на себе обчислення властивостей (`sums`, `centroid`), вирішуючи, чи використовувати просту суму, чи надійну інтеграцію контуру.
