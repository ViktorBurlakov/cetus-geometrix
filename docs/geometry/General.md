# 🛠️ Документація Системи Геометричних Властивостей (CSG Tree Implementation)

## 1. Архітектура: CSG-Дерево

Система використовує архітектуру **Конструктивної Солідної Геометрії (CSG) у формі бінарного дерева**. Кожен геометричний об'єкт є вузлом у цьому дереві.

| Тип Вузла | Класи | Операція | Характеристика |
| :--- | :--- | :--- | :--- |
| **Листовий Вузол (Primitive)** | `Rectangle`, `Circle`, `Polygon`, `CircularArc`, **`BSpline`** | `OperationType.PRIMITIVE` | Зберігає геометричні параметри та обчислює I_c / I_0 аналітично або чисельно. |
| **Операційний Вузол (Compound)** | `Compound` | `UNION`, `DIFFERENCE`, `INTERSECTION` | Зберігає **лівий операнд (`left`)** та **правий операнд (`right`)** і тип булевої операції. |

**CSG-Арифметика**: Оператори `+`, `-`, `*` **завжди** створюють новий батьківський `Compound`-вузол, що гарантує збереження повної історії операцій.

## 2. Системи Координат та Розрахунки (I_0 та I_c)

Як і раніше, використовується Теорема Штейнера для переходу між системами:

* **Глобальна (I_0)**: Відносно початку координат (0, 0).
* **Центроїдальна (I_c)**: Відносно центру мас об'єкта.

**Розрахунковий Потік**:

1.  **Примітиви (Аналітичні)**: I_c $\to$ **Прямий Трансфер Штейнера** $\to$ I_0.
2.  **Примітиви (Чисельні)**: Гаусс-Гріна $\to$ I_0 $\to$ **Зворотний Трансфер Штейнера** $\to$ I_c.
3.  **Compound**: Рекурсивно виконує булеву операцію Shapely $\to$ Отримує фінальну геометрію $\to$ Гаусс-Гріна на фінальній геометрії (включаючи отвори) $\to$ I_0 $\to$ Зворотний Трансфер $\to$ I_c.

## 3. Особливості Класів

| Клас | Розрахунковий Метод | Реалізація Кривих/Геометрії | Особливість CSG-Дерева |
| :--- | :--- | :--- | :--- |
| **`Rectangle`** | Аналітичний | Прямі лінії | Листовий Вузол (PRIMITIVE) |
| **`Circle`** | Аналітичний | Полігональна апроксимація | Листовий Вузол (PRIMITIVE) |
| **`Polygon`** | Чисельний (Гаусс-Гріна) | Задані точки | Листовий Вузол (PRIMITIVE) |
| **`CircularArc`** | Чисельний (Гаусс-Гріна) | Полігональна апроксимація сектору | Листовий Вузол (PRIMITIVE) |
| **`BSpline`** | **Чисельний (SciPy CubicSpline)** | **Використовує SciPy для генерації гладкої полілінії з контрольних точок.** | **Листовий Вузол (PRIMITIVE)** |
| **`Compound`** | Топологічний (Shapely) | **Рекурсивно** виконує `union`, `difference`, `intersection` | **Операційний Вузол** (Зберігає `left`, `right` та `op_type`) |

### Деталі BSpline

* Використовує **`scipy.interpolate.CubicSpline`** для інтерполяції.
* Контрольні точки (`vertices_list`) параметризуються за кумулятивною довжиною.
* Параметр **`num_points`** контролює точність апроксимації кривої полігоном.
* Обчислення I_0 та I_c виконується чисельно, оскільки сплайн представлений як багатокутник.
