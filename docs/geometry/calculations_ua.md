# 📚 Теорія та API-довідник: calculations.py (Основні Математичні Алгоритми)

Модуль `calculations.py` є математичним ядром бібліотеки, що містить універсальні функції для чисельного розрахунку та перетворення геометричних властивостей 2D-перерізів.

---

## 1. `calculate_vertices_sums` (Метод Гаусса-Гріна)

Ця функція виконує чисельну інтеграцію для багатокутників, обчислюючи **сирі геометричні суми ($I_0$)** відносно глобального початку координат $(0, 0)$.

### Призначення
Забезпечує точний розрахунок властивостей для чисельних примітивів (`Polygon`, `CircularArc`, `BSpline`) та складних CSG-об'єктів.

### Ключові Формули (I_0)
* **Площа (A):**
    $$A = \frac{1}{2} \sum (x_i y_{i+1} - x_{i+1} y_i)$$
* **Статичні Моменти ($S_{x0}, S_{y0}$):**
    $$S_{x0} = \frac{1}{6} \sum (y_i + y_{i+1}) (x_i y_{i+1} - x_{i+1} y_i)$$
    $$S_{y0} = \frac{1}{6} \sum (x_i + x_{i+1}) (x_i y_{i+1} - x_{i+1} y_i)$$
* **Момент Інерції ($I_{xx0}$) відносно $(0, 0)$:**
    $$I_{xx, 0} = \frac{1}{12} \sum (y_i^2 + y_i y_{i+1} + y_{i+1}^2) (x_i y_{i+1} - x_{i+1} y_i)$$

## 2. `transfer_properties` (Теорема Штейнера)

Універсальна функція для перенесення моментів інерції між паралельними осями.

### Формула Штейнера
$$I_{\text{new}} = I_{\text{old}} \pm A \cdot d^2$$
де $I$ — момент інерції, $A$ — площа, $d$ — відстань між паралельними осями.

### Режими
| Параметр `reverted` | Режим | Призначення | Формула |
| :---: | :--- | :--- | :--- |
| **`False`** | **Прямий Трансфер** | $I_c \to I_0$. Перенесення від центроїда до $(0, 0)$. | $I_{0} = I_{c} + A \cdot d^2$ |
| **`True`** | **Зворотний Трансфер** | $I_0 \to I_c$. Перенесення від $(0, 0)$ до центроїда. | $I_{c} = I_{0} - A \cdot d^2$ |

### Обчислення Статичних Моментів при Трансфері
* **Прямий Трансфер:** Встановлює статичні моменти щодо $(0, 0)$: $S_{x0} = A \cdot c_y, S_{y0} = A \cdot c_x$.
* **Зворотний Трансфер:** Обнуляє статичні моменти, оскільки вони відносно центроїда ($S_x=0, S_y=0$).

## 3. `calculate_principal_axes` (Головні Моменти Інерції)

Обчислює головні моменти інерції ($I_1, I_2$) та кут повороту ($\alpha$) головних осей, використовуючи принципи **Кола Мора**.

### Ключові Елементи Кола Мора
1.  **Середній Момент ($I_{\text{avg}}$):** Центр кола.
    $$I_{\text{avg}} = \frac{I_{xx}^c + I_{yy}^c}{2.0}$$
2.  **Радіус ($R$):** Радіус кола.
    $$R = \sqrt{\left(\frac{I_{xx}^c - I_{yy}^c}{2.0}\right)^2 + (I_{xy}^c)^2}$$

### Розрахунок Властивостей
* **Головні Моменти:**
    $$I_1 = I_{\text{avg}} + R \quad (\text{Максимальний})$$
    $$I_2 = I_{\text{avg}} - R \quad (\text{Мінімальний})$$
* **Кут Повороту ($\alpha$):** Кут, на який потрібно повернути центроїдальні осі для збігу з головними осями.
    $$\alpha = \frac{1}{2} \arctan \left( \frac{2 I_{xy}^c}{I_{y}^c - I_{x}^c} \right)$$
    *Примітка: У коді використовується функція `math.atan2` для забезпечення стійкості розрахунку кута в усіх квадрантах*.

## 4. `calculate_radii_of_gyration` (Радіуси Інерції)

Обчислює радіуси інерції ($r_x, r_y, r_1, r_2$) для перерізу.

### Формула
Радіус інерції визначається як відстань, на якій повинна бути зосереджена вся площа перерізу, щоб забезпечити такий самий момент інерції, як і фактичний переріз.
$$r = \sqrt{I / A}$$

### Обчислювані Радіуси
* $r_x, r_y$: Радіуси інерції відносно центроїдальних осей ($I_{xx}^c, I_{yy}^c$).
* $r_1, r_2$: Радіуси інерції відносно головних осей ($I_1, I_2$).
