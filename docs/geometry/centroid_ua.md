# 📚 Розширена Теорія: `centroid.py` (Інженерне Значення)

Модуль `centroid.py` визначає клас **`Centroid`**. Цей клас є центральною точкою даних, що зберігає **всі мінімальні геометричні та інерційні властивості** об'єкта, обчислені відносно його **Центру Мас (ЦМ)**.

---

## 1. 🎯 Фізичне Значення Центру Мас (ЦМ)

Поле **`center`** (координати $X_c, Y_c$) визначає ЦМ. Ця локація має критичне значення, оскільки:
* **Моменти Інерції Мінімізовані:** Згідно з **Теоремою Штейнера**, моменти інерції, обчислені відносно осей, що проходять через ЦМ, завжди є **найменшими** для даного перерізу.
* **Нульові Статичні Моменти:** У точці ЦМ статичні моменти дорівнюють нулю ($S_x = 0$ та $S_y = 0$). Це гарантує, що при чистому згині нейтральна вісь співпадає з віссю ЦМ.

## 2. 🛡️ Центроїдальний Тензор Інерції (`inertia`)

Поле **`inertia`** містить **мінімальні, центроїдальні моменти** ($I_{xx}^c, I_{yy}^c, I_{xy}^c$), які є основою для всіх розрахунків на міцність.

### Застосування у Механіці Матеріалів
Центроїдальний момент інерції ($I$) є обов'язковим для **формули напружень згинання** (Ейлера-Бернуллі):
$$\sigma = \frac{M \cdot y}{I}$$
Для точного розрахунку максимальних нормальних напружень ($\sigma$) у балці, $I$ **мусить** бути центроїдальним моментом ($I_{xx}^c$ або $I_{yy}^c$).

## 3. 🌀 Головні Моменти Інерції (`principal_moments`)

Ця властивість (отримана за допомогою **Кола Мора**) визначає природну жорсткість та орієнтацію перерізу.
* **$I_1$ (Максимальний):** Момент інерції навколо **найжорсткішої осі**.
* **$I_2$ (Мінімальний):** Момент інерції навколо **найслабшої осі**.
* **$\alpha$ (Кут повороту):** Кут, на який потрібно повернути центроїдальні осі, щоб вони збіглися з головними осями.

### Застосування у Стійкості Конструкцій (Buckling)
Для розрахунку **критичного навантаження Ейлера** ($P_{cr}$) на колону, $I$ слід приймати як **мінімальний головний момент ($I_2$)**, оскільки колона завжди втратить стійкість у напрямку найменшої жорсткості.
$$P_{cr} = \frac{\pi^2 E I_2}{L_{eff}^2}$$

## 4. ⚖️ Радіуси Інерції (`radii_of_gyration`)

Радіус інерції ($r$) — це **показник геометричної ефективності** перерізу.
$$\text{Радіус інерції} \quad r = \sqrt{I / A}$$

### Застосування у Розрахунку Гнучкості
Мінімальний радіус інерції ($r_{min} = r_2$) є ключовим для обчислення **Гнучкості** ($\lambda$) колони:
$$\lambda = \frac{L_{eff}}{r_{min}}$$
Показник гнучкості використовується для визначення того, чи є колона короткою, середньою чи довгою, що має прямий вплив на її несучу здатність.
