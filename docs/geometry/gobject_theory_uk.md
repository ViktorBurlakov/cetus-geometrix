# 📚 Теорія: Абстрактний Геометричний Об'єкт (`GeometryObject`)

## 1. Концепція Базового Інтерфейсу

`GeometryObject` – це **абстрактний базовий клас (ABC)**, який слугує єдиним інтерфейсом для всіх геометричних сутностей у системі `geometrix`. Кожен об'єкт (2D переріз, 3D тіло) успадковує функціональність, необхідну для:
1.  Інтеграції в **Конструктивну Твердотільну Геометрію (CSG)**.
2.  Обчислення **інерційних властивостей**.

### 1.1. Роль у CSG-дереві
Кожен `GeometryObject` є вузлом у CSG-дереві, де поле `op_type` визначає, як цей вузол взаємодіє з іншими.

* **`OperationType.PRIMITIVE`**: Вузли-листи (базові фігури).
* **Булеві Оператори (`__add__`, `__sub__`, `__mul__`)**: Перевизначаються в похідних класах для створення складних об'єктів через об'єднання, віднімання або перетин.

## 2. Фундаментальні Властивості (Абстрактні)

Три абстрактні властивості є основою для всіх розрахунків і повинні бути реалізовані в кожному конкретному геометричному класі:

| Властивість | Призначення | Обчислюється відносно |
| :--- | :--- | :--- |
| **`sums`** | **Сирі Геометричні Суми (`GeometrySums`)** – об'єм, статичні моменти ($S_x, S_y, S_z$) та моменти інерції ($I_{x0}, I_{y0}, \dots$). | **Глобального Початку** $(0,0,0)$. |
| **`centroid`** | **Центроїдальні Властивості (`Centroid`)** – координати центру мас/центроїда та моменти інерції, перенесені на центроїдальні осі. | **Центру Мас** $(\bar{x}, \bar{y}, \bar{z})$. |
| **`primary_measure`** | Основна міра об'єкта: **Площа** (2D) або **Об'єм** (3D). | - |

## 3. Обчислення Координат Центроїда

Базовий клас `GeometryObject` містить реалізації для обчислення координат центроїда ($c_x, c_y, c_z$) на основі сирих геометричних сум:

* **$c_x$ (X-координата)**:
    $$c_x = \frac{S_y}{\text{Primary Measure}}$$
* **$c_y$ (Y-координата)**:
    $$c_y = \frac{S_x}{\text{Primary Measure}}$$
* **$c_z$ (Z-координата)**:
    $$c_z = \frac{S_z}{\text{Primary Measure}}$$

Обчислення захищено від ділення на нуль за допомогою глобальної константи `TOLERANCE.AREA_CALC`.
