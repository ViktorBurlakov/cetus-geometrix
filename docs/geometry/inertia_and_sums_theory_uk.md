# 📚 Теорія: Геометричні Суми та Тензори Інерції

## 1. Базові Геометричні Структури

### 1.1. Точність та Координати
* **`TOLERANCE`**: Визначає глобальні константи точності. Це критично для порівнянь з плаваючою комою та для уникнення помилок ділення на нуль (наприклад, при обчисленні центроїда).
* **`Vertex`**: Основний DTO для представлення точки у просторі ($x, y, z$). У 2D-геометрії координата $z$ залишається нульовою.

### 1.2. Булеві Операції (`OperationType`)
Енумератор використовується для визначення типу операції у вузлах CSG-дерева (Конструктивна Твердотільна Геометрія). Це дозволяє програмістично моделювати складні форми:
* `UNION` (Об'єднання): Додавання властивостей.
* `DIFFERENCE` (Віднімання): Віднімання властивостей (наприклад, моделювання отвору).

## 2. Моменти Першого Порядку (Статичні Моменти)

### `StaticMoments`
Цей клас інкапсулює **Статичні Моменти ($S$)** об'єкта відносно глобального початку координат $(0, 0, 0)$.

* **Призначення**: Критичні для знаходження **Центроїда (Center of Mass)** перерізу або тіла:
    $$\text{Центроїд } (\bar{x}, \bar{y}) = \left( \frac{S_y}{A}, \frac{S_x}{A} \right)$$
* **Операції**: Методи `__add__` та `__sub__` дозволяють коректно агрегувати статичні моменти відповідно до булевих операцій.

## 3. Моменти Другого Порядку (Тензор Інерції)

### `InertiaTensor`
Цей клас є універсальною формою для зберігання **Моментів та Добутків Інерції** відносно глобального початку координат (Моменти Другого Порядку).

| Компонент | Тип | 2D (Площа) | 3D (Маса) |
| :--- | :--- | :--- | :--- |
| **Ixx, Iyy, Izz** | Моменти Інерції | Осьові Моменти Площі | Масові Моменти Інерції |
| **Ixy, Ixz, Iyz** | Добутки Інерції | Добутки Інерції Площі | Масові Добутки Інерції |
| **J_torsion** | Константа Кручення | Визначає крутильну жорсткість ($GJ$) | - |

* **$I_{\text{polar}}$**: Полярний момент інерції (сума $I_{xx} + I_{yy}$).
* **Метод `ndarray`**: Перетворює компоненти тензора в матрицю **2x2** (для 2D) або **3x3** (для 3D).

## 4. Агрегація та Перетворення

### 4.1. Зведені Геометричні Суми (`GeometrySums`)
Це центральний DTO, що зберігає всі "сирі" інтегральні властивості:
* **Первинні Міри**: Площа перерізу, Об'єм, Площа Поверхні.
* **Моменти**: `StaticMoments` та `InertiaTensor`.

Ці "сирі" суми є вхідними даними для Теорії Паралельних Осей (Теорема Штайнера), яка переносить моменти з глобального початку на центроїдальні осі.

### 4.2. Головні Властивості

* **`PrincipalInertia`**: Містить **Головні Моменти Інерції ($I_1, I_2$)** та **Кут Повороту ($\alpha$)**. Вони представляють мінімальний та максимальний опір згину або обертанню в площині.
* **`RadiiOfGyration`**: Містить **Радіуси Інерції ($r$)** відносно центроїдальних осей та головних осей. Вони є мірою розподілу маси/площі і використовуються у розрахунках стійкості (гнучкості) елементів:
    $$r = \sqrt{\frac{I_{\text{центроїд}}}{M \text{ або } A}}$$
