# 💡 Теоретичні Основи Модуля `primitives.py` (2D Перерізи)

Модуль `primitives.py` є інженерним ядром бібліотеки для моделювання та обчислення **Геометричних Властивостей** 2D-перерізів. Його основна мета — забезпечення точних розрахунків **Площі (A)**, **Статичних Моментів ($S_x, S_y$)** та **Моментів Інерції ($I_{xx}, I_{yy}, I_{xy}$) **.

---

## 1. Фундаментальні Моделі Даних

Модуль `primitives.py` сильно залежить від моделей даних, визначених у `geometrix.geometry.models`:

1.  **`Vertex`:** Мінімальна структура для зберігання координат точки (x, y).
2.  **`InertiaTensor`:** Містить моменти інерції ($I_{xx}, I_{yy}$) та відцентровий момент інерції ($I_{xy}$).
3.  **`Centroid`:** Комбінує площу, координати центру ($c_x, c_y$) та центроїдальні моменти інерції ($I_c$).
4.  **`GeometrySums`:** Містить фінальні обчислені властивості щодо початку координат $(0, 0)$.

---

## 2. Методологія Розрахунку Властивостей

Модуль розділяє примітиви на дві категорії, відповідно до їхнього методу обчислення властивостей.

### A. Аналітичні Примітиви (`Rectangle`, `Circle`)

Розрахунок базується на **точних, замкнених формулах**.

* **Етап 1: Власний Центроїд ($I_c$)**
    Властивості (наприклад, $A, I_{xx}, I_{yy}$) обчислюються за класичними формулами відносно власного центру маси. Для прямокутника $I_{xx, c} = \frac{bh^3}{12}$, $I_{yy, c} = \frac{hb^3}{12}$.
* **Етап 2: Трансфер Штейнера (Steiner Transfer)**
    Для отримання фінальних `GeometrySums` (щодо глобального початку координат $I_0$) використовується **Прямий Трансфер Штейнера** (`transfer_properties` з `calculations`):
    $$\text{Direct Steiner Transfer: } I_{0} = I_{c} + A \cdot d^2$$
    де $d$ — зміщення центроїда об'єкта відносно осі (наприклад, $d=c_y$ для $I_{xx}$).

### B. Чисельні Примітиви (`Polygon`, `CircularArc`, `BSpline`)

Ці об'єкти використовують **чисельне інтегрування** контуру. `CircularArc` та `BSpline` спочатку апроксимуються як `Polygon`.

* **Етап 1: Обчислення щодо Початку Координат ($I_0$)**
    Для багатокутника використовується **Формула Гаусса-Гріна** (Gauss-Green Formula), реалізована у функції `calculate_vertices_sums`. Для послідовності вершин $(x_i, y_i)$:
    * **Площа ($A$):**
        $$A = \frac{1}{2} \sum_{i=1}^{n} (x_i y_{i+1} - x_{i+1} y_i)$$
    * **Статичні Моменти ($S_x, S_y$):**
        $$S_x = \frac{1}{6} \sum_{i=1}^{n} (x_i y_{i+1} - x_{i+1} y_i) (y_i + y_{i+1})$$
        $$S_y = \frac{1}{6} \sum_{i=1}^{n} (x_i y_{i+1} - x_{i+1} y_i) (x_i + x_{i+1})$$
    * **Моменти Інерції ($I_{xx}, I_{yy}, I_{xy}$) щодо $(0, 0)$:**
        $$I_{xx, 0} = \frac{1}{12} \sum_{i=1}^{n} (x_i y_{i+1} - x_{i+1} y_i) (y_i^2 + y_i y_{i+1} + y_{i+1}^2)$$
        $$I_{yy, 0} = \frac{1}{12} \sum_{i=1}^{n} (x_i y_{i+1} - x_{i+1} y_i) (x_i^2 + x_i x_{i+1} + x_{i+1}^2)$$
* **Етап 2: Обчислення Центроїда та Зворотний Трансфер**
    * Координати Центроїда: $c_x = S_y / A$ та $c_y = S_x / A$.
    * Застосовується **Зворотний Трансфер Штейнера** (`transfer_properties` з `reverted=True`) для отримання $I_c$:
    $$\text{Inverse Steiner Transfer: } I_{c} = I_{0} - A \cdot d^2$$

## 3. Конструктивна Геометрія Тіла (CSG)

Клас **`Compound`** будує бінарне CSG-дерево і обробляє складні фігури.

### A. Топологія (Shapely)

Властивість `shapely_geometry` відповідає за створення фактичного контуру. Вона рекурсивно виконує булеві операції (`UNION`, `DIFFERENCE`, `INTERSECTION`) над операндами (`left`, `right`) за допомогою бібліотеки **Shapely** (GEOS).

### B. Розрахунок Властивостей `Compound`

Властивості (зокрема `sums` та `centroid`) обчислюються шляхом **делегування** логіки об'єкту `CSGOperation`.

1.  **Остаточна Форма:** Спочатку отримується фінальна Shapely-геометрія.
2.  **Розрахунок:** Для отримання точних властивостей фінальної, складеної фігури (особливо з отворами), обчислення виконується **чисельно** на основі **вершин фінального контуру**, використовуючи той самий механізм $I_0 \to I_c$ як для звичайного `Polygon`.

Це гарантує, що незалежно від складності CSG-дерева, властивості завжди будуть відповідати фактичному контуру фінального перерізу.
