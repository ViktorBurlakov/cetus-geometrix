# 📚 Теорія: Моделювання Матеріалів (`material/models.py`)

## 1. Призначення Модуля
Модуль `material/models.py` є фундаментальним для будь-якого інженерного аналізу, що передбачає взаємодію з фізичними об'єктами. Він містить **базову модель даних (DTO) `Material`**, яка інкапсулює ключові фізичні та механічні властивості інженерного матеріалу.

Ця модель є незмінною (immutable) та забезпечує валідацію даних завдяки використанню Pydantic.

## 2. Ключові Інженерні Концепції та Властивості

### 2.1. Щільність (`density`)
* **Опис**: Маса матеріалу на одиницю об'єму [кг/м³].
* **Значення в інженерії**: Використовується для розрахунку маси та інерційних характеристик елементів, що є критично важливим для динамічного аналізу та визначення навантажень від власної ваги.

### 2.2. Модуль Юнга (`E`, Модуль пружності)
* **Опис**: Міра опору матеріалу пружній деформації під дією осьового навантаження (розтягування або стискання) [Па].
* **Формула**: $E = \sigma / \varepsilon$, де $\sigma$ — нормальне напруження, $\varepsilon$ — лінійна деформація.
* **Значення в інженерії**: Фундаментальний параметр для розрахунку згинальних та осьових жорсткостей. Високий $E$ вказує на високу жорсткість.

### 2.3. Коефіцієнт Пуассона (`nu`)
* **Опис**: Безрозмірна величина, що описує відношення відносної поперечної деформації до відносної поздовжньої деформації [безрозмірний].
* **Значення в інженерії**: Впливає на розрахунок модуля зсуву та використовується в теорії пружності для врахування поперечних деформацій.

### 2.4. Модуль Зсуву (`shear_modulus`, $G$)
* **Опис**: Міра опору матеріалу деформації зсуву [Па].
* **Формула (для ізотропних матеріалів)**:
    $$G = \frac{E}{2(1 + \nu)}$$
* **Значення в інженерії**: Критично важливий для розрахунку крутильної та зсувної жорсткості елементів. Для більшості металів $G \approx 0.38 \cdot E$.

**Важливо**: Модель `Material` є основою для визначення жорсткісних властивостей будь-якого інженерного елемента, агрегуючи ці фундаментальні константи.
