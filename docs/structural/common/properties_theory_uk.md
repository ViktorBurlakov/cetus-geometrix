# 📚 Теорія: Властивості Структурних Елементів (`properties.py`)

## 1. Призначення Модуля та Архітектурна Роль
Модуль `properties.py` є фундаментальним для будь-якого структурного аналізу. Він містить **моделі даних (DTOs)**, які описують фізичні характеристики структурних елементів:
* **Жорсткісні властивості**: Опір деформаціям (згинання, кручення, осьові, зсувні).
* **Інерційні властивості**: Розподіл маси та інерції вздовж елемента.
* **Параметри дискретизації**: Як елемент розбитий на секції для чисельного розрахунку.

Ці моделі є *загальними* для різних типів аналізу і слугують вхідними даними для вирішувачів (солверів).

## 2. Ключові Інженерні Концепції

### Розподілені та Інтегральні Характеристики

#### 2.1. Погонні (Розподілені) Характеристики
Це властивості, що відносяться до одиниці довжини елемента. Вони дозволяють моделювати елементи зі змінним перерізом або матеріалом вздовж його осі.
* **Погонна маса ($m'$)**: Маса, розподілена на одиницю довжини [кг/м].
* **Погонний момент інерції маси ($I_m'$)**: Момент інерції маси, розподілений на одиницю довжини [кг·м²/м].

#### 2.2. Жорсткісні Характеристики
Описують здатність елемента чинити опір деформаціям під дією навантажень.
* **Згинальна жорсткість ($EI$)**: Добуток модуля Юнга ($E$) та моменту інерції площі поперечного перерізу ($I$). Характеризує опір елемента згину [Н·м²].
* **Крутильна жорсткість ($GJ$)**: Добуток модуля зсуву ($G$) та полярного моменту інерції площі перерізу ($J$). Характеризує опір елемента крученню [Н·м²].
* **Осьова жорсткість ($EA$)**: Добуток модуля Юнга ($E$) та площі поперечного перерізу ($A$). Характеризує опір елемента осьовим деформаціям (розтягнення/стиснення) [Н].
* **Зсувна жорсткість ($GA_{shear}$)**: Добуток модуля зсуву ($G$) та ефективної площі зсуву ($A_{shear}$). Характеризує опір елемента зсувним деформаціям [Н].

### 3. Дискретизація Лінійних Структур

Для чисельних методів аналізу (таких як метод скінченних елементів або метод послідовних наближень), неперервна структурна модель розбивається на скінченну кількість дискретних ділянок.
* **`section_count` (N)**: Кількість дискретних секцій. Це означає, що елемент матиме $N+1$ точок (вузлів), в яких визначені властивості.
* **`z_coords`**: Масив Z-координат цих $N+1$ точок.
* Всі розподілені властивості (`m_prime_array`, `EI_y_array` тощо) задаються у вигляді масивів довжиною $N+1$, відповідаючи цим точкам.

Це дозволяє моделювати елементи зі змінними властивостями вздовж їх довжини (наприклад, конічні балки або балки з різними матеріалами).
