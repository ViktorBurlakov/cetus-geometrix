# 📚 Теорія: Звітність про Результати (`results.py`)

## 1. Призначення Модуля
Модуль `results.py` містить універсальні **моделі даних (DTOs)** для стандартизованого звітування про результати чисельних розрахунків. Основний клас, `ConvergenceReport`, забезпечує чітке та послідовне представлення інформації про виконання солвера.

## 2. Звіт про Збіжність (Convergence Report)

### 2.1. Теоретичне Обґрунтування
Більшість складних інженерних задач вирішуються за допомогою **ітераційних чисельних методів**. Це означає, що розрахунок виконується покроково, повторюючи обчислення доти, доки не буде досягнуто достатньої точності.

**Звіт про збіжність** є критично важливим для оцінки успішності та ефективності такого розрахунку:
* **Збіжність (Convergence)**: Чи досяг алгоритм бажаної точності? Якщо ні, чому? (наприклад, через перевищення максимальної кількості ітерацій або через нестійкість методу).
* **Ефективність**: Скільки ітерацій було потрібно? Скільки часу зайняв розрахунок?

### 2.2. Ключові Атрибути Звіту

| Атрибут | Призначення |
| :--- | :--- |
| `iteration_count` | Загальна кількість ітерацій, виконаних солвером. |
| `convergence_met` | Булеве значення, що вказує, чи було досягнуто критерію збіжності в межах заданої `tolerance` та `max_iter`. |
| `error_message` | Рядок, що містить повідомлення про помилку, якщо розрахунок не зійшовся (наприклад, "Max iterations exceeded"). |
| `computation_time_s` | Загальний час, витрачений на розрахунок, у секундах. |

Ця стандартизована звітність дозволяє легко інтегрувати солвери в більші системи та автоматизувати перевірку результатів.
