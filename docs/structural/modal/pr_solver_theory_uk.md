# 📚 Теорія: Метод Послідовних Наближень (P.I.M.) (`pr_solver.py`)

## 1. Призначення Модуля
Модуль `pr_solver.py` містить конкретну реалізацію вирішувача для **модального аналізу** одновимірних стрижневих систем. Клас `ProgressiveIterationSolver` використовує **Метод Послідовних Наближень (Progressive Iteration Method - P.I.M.)**, також відомий як метод ітерацій Прандтля-Рітца або Стодоли-Віанелло.

Цей солвер призначений для знаходження **першого власного тону** (частоти та форми) для:
* **Згинальних коливань** (bending modes).
* **Крутильних коливань** (torsional modes).

## 2. Теоретичні Основи Метод Послідовних Наближень (P.I.M.)

Метод P.I.M. є ітераційним методом для визначення найнижчих власних частот, особливо ефективним для систем з розподіленими масами та жорсткостями. Він базується на чисельному інтегруванні диференціальних рівнянь вільних коливань елемента.

### 2.1. Алгоритм P.I.M.

1.  **Початкове наближення форми коливань ($f_0$)**:
    * На початку розрахунку необхідно задати деяку початкову форму коливань. Для згину це може бути, наприклад, статичний прогин від рівномірно розподіленого навантаження. Для кручення — статичний кут закручування. Якість цього наближення впливає на швидкість збіжності.

2.  **Гіпотеза інерційного навантаження**:
    * На кожній ітерації $k$, поточна форма коливань $f_{k-1}$ використовується для обчислення гіпотетичного розподілу **інерційного навантаження** ($q_i$):
        $$q_{i, k-1}(z) = \omega_{k-1}^2 \cdot m'(z) \cdot f_{k-1}(z)$$
    * де $\omega_{k-1}^2$ — квадрат власної частоти з попередньої ітерації, $m'(z)$ — погонна маса.

3.  **Чисельне інтегрування**:
    * Інерційне навантаження $q_{i, k-1}(z)$ розглядається як статичне навантаження, і шляхом послідовного інтегрування (з відповідними граничними умовами) визначається **нова, уточнена форма коливань** $f_k(z)$.
    * **Для згинальних коливань**: Виконується чотирикратне інтегрування:
        $$f_k(z) = \frac{1}{EI(z)} \iiint \int q_{i, k-1}(z) dz dz dz dz$$
    * **Для крутильних коливань**: Виконується двократне інтегрування:
        $$\phi_k(z) = \frac{1}{GJ(z)} \iint m_t(z) dz dz$$
        де $m_t(z)$ — розподілений інерційний крутний момент.

4.  **Уточнення власної частоти ($\omega_k$)**:
    * Нове значення власної частоти обчислюється, як правило, на основі співвідношення максимальних амплітуд старої та нової форм коливань, або через енергетичні співвідношення (формула Релея). Наприклад:
        $$\omega_k^2 = \frac{\int m'(z) f_{k-1}(z)^2 dz}{\int m'(z) f_{k-1}(z) f_k(z) dz} \approx \frac{\max(f_{k-1})}{\max(f_k)}$$

5.  **Перевірка збіжності**:
    * Процес ітерацій повторюється доти, доки відносна різниця між двома послідовними значеннями власної частоти ($\omega_k$ та $\omega_{k-1}$) не стане меншою за задану `tolerance`.

### 2.2. Застосування в `ProgressiveIterationSolver`

* Метод `_run_single_mode` керує ітераційним циклом для одного типу коливань (згин або кручення).
* Метод `perform_iteration` виконує один крок алгоритму P.I.M. (розрахунок навантаження, інтегрування).
* Метод `execute` координує виконання аналізу для обох типів коливань та агрегує кінцеві результати.

**Обмеження**: P.I.M. зазвичай знаходить лише **перший (найнижчий)** власний тон для кожного типу коливань. Для знаходження вищих тонів потрібні більш складні методи (наприклад, метод послідовних наближень з дефляцією або методи на основі матричних розрахунків).
