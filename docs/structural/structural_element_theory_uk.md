# 📚 Теорія: Структурний Елемент (`structural/models.py`)

## 1. Призначення Модуля
Модуль `structural/models.py` містить високоуровневу **модель `StructuralElement`**. Цей клас є ключовим агрегатором, який об'єднує два основні аспекти будь-якого фізичного інженерного компонента:
1.  **Геометрія (`Solid`)**: Яку форму має елемент?
2.  **Матеріал (`Material`)**: З чого він зроблений?

Це центральний DTO (Data Transfer Object), що створює повний контекст опису об'єкта перед тим, як його властивості будуть підготовлені для чисельного аналізу (дискретизовані, перетворені на жорсткості тощо).

## 2. Архітектурний Патерн: Агрегація (Composition)

Клас `StructuralElement` реалізує патерн **агрегації (Composition)**. Замість того, щоб містити всі геометричні та матеріальні властивості безпосередньо, він *має* посилання на інші об'єкти, які інкапсулюють ці дані:
* `solid`: Об'єкт типу `Solid`, який надає інформацію про об'єм, центр мас, моменти інерції.
* `material`: Об'єкт типу `Material`, що надає інформацію про щільність, модулі пружності.

Це забезпечує:
* **Розділення відповідальності**: Кожен клас відповідає лише за свій аспект (Solid за геометрію, Material за матеріал).
* **Гнучкість**: Легко замінювати або розширювати типи геометрії чи матеріалів без зміни `StructuralElement`.
* **Чіткість**: Код стає легшим для розуміння та підтримки.

## 3. Обчислювані Властивості (Derived Properties)

На основі агрегованих даних, `StructuralElement` може обчислювати важливі похідні властивості:

### 3.1. Маса (`mass`)
* **Опис**: Загальна маса елемента [кг].
* **Формула**: $$M = \text{Solid.volume} \cdot \text{Material.density}$$
* **Значення в інженерії**: Фундаментальний параметр для динамічного аналізу, розрахунку інерційних навантажень та визначення ваги конструкції.

### 3.2. Головні Моменти Інерції Маси (`principal_inertia`)
* **Опис**: Інерційні характеристики маси відносно головних осей. Вони описують опір тіла обертальному руху [кг·м²].
* **Значення в інженерії**: Критично важливі для динамічного аналізу, особливо для розрахунку крутильних коливань та стійкості до обертання. Ці значення зазвичай вже обчислені геометричною моделлю `Solid`.

### 3.3. Радіуси Інерції (`radii_of_gyration`)
* **Опис**: Відстань від осі обертання, на якій повинна бути зосереджена вся маса тіла, щоб його момент інерції відносно цієї осі залишався незмінним [м].
* **Значення в інженерії**: Використовуються для швидкої оцінки інерційних властивостей та в деяких формулах стійкості. Також зазвичай вже обчислені геометричною моделлю `Solid`.

**Висновок**: `StructuralElement` є своєрідним "паспортом" інженерного об'єкта, що збирає всі базові характеристики, необхідні для подальшого, більш детального аналізу.
